# opai-agents-tools

Ready-made tools: calculator, clock, read-only files and a URL fetcher that stays off the private network.

Part of the Rust port of the OpenAI Agents SDK. Start from the
[`opai-agents`](https://crates.io/crates/opai-agents) crate, which re-exports everything; the
documentation, examples and the list of differences from the Python SDK are in the
[repository](https://github.com/charleslyh/openai-agents-rs).
